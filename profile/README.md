### Finium Legal — open tooling for verifiable evidence

[finiumlegal.com](https://finiumlegal.com) builds the Evidence Desk for online-harm legal work: monitoring, capture, and structured evidence packs across EU jurisdictions.

We keep the **verifier open** so evidence recipients never have to trust us:

- **[evidence-verify](https://github.com/FiniumAI/evidence-verify)** — an offline, standard-library-only Python verifier for tamper-evident evidence packs: hash manifest, root hash, chain-of-custody log, RFC 3161 timestamp tokens. Its docs spell out exactly what a verified pack proves — and what it does *not* prove (see its security notes). Apache-2.0, so courts, journalists, auditors, and capture vendors can adopt the pack format independently of us.
